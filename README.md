# QuizForge

A versatile educational platform to create, share, and take quizzes on any subject. Forge your knowledge and challenge others.

## Features
- **User Authentication:** Sign up and log in to manage your quizzes and track attempts.
- **Dynamic Quiz System:** Take multiple-choice quizzes on any topic.
- **Create & Share:** Create custom quizzes and share them with a unique ID.
- **Performance Analytics:** View detailed results and track participant performance.
- **Admin Dashboard:** Manage users, quizzes, and monitor activity.

## Technology Stack
- **Frontend:** HTML5, CSS3 (Vanilla), JavaScript
- **Backend:** Python (Flask)
- **Database:** SQLite

## How to Run
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the application:
   ```bash
   python app.py
   ```
3. Open your browser and navigate to `http://127.0.0.1:5000`
